
# 📊 Проект: Telegram-бот для анализа российского рынка

## 🎯 Цель проекта
Создать Telegram-бота, который ежедневно (утром и вечером) анализирует финансовые данные (акции, фьючерсы, индексы) и присылает сигналы по техническим индикаторам (дивергенции) с указанием конкретных дат, цен и рекомендуемых действий.

## 👤 Автор
Data Engineer, развивает навыки в области анализа данных, работы с API и DevOps.

---

## 🛠️ Технологический стек

| Компонент | Инструмент | Назначение |
| :--- | :--- | :--- |
| **Язык** | Python 3.11+ | Весь код написан на Python |
| **Библиотеки** | `pandas`, `numpy`, `aiohttp`, `aiogram`, `apscheduler`, `pyyaml`, `loguru` | Обработка данных, HTTP-запросы, Telegram-бот, планировщик, логирование |
| **База данных** | SQLite (`finance.db`) | Хранение исторических свечей (OHLCV) и метаданных |

| **Контейнеризация** | Docker | Для деплоя на бесплатный VPS (Oracle Cloud Always Free) |
| **Оркестрация** | Docker Compose (в перспективе) | Для управления несколькими сервисами |

## 📦 Функциональность модулей (что уже работает)

### 1. `database.py` – работа с SQLite
- Создание таблиц `raw_candles`, `continuous_ohlc`, `meta`.
- Методы: `insert_raw_candles`, `insert_continuous_candles`, `get_last_ts`, `upsert_meta`.
- Все данные хранятся в Unix timestamp (`ts` INTEGER) для производительности.

### 2. `moex_loader.py` – загрузка с MOEX
- Метод `fetch_candles_async(secid, asset_type, from_date, till_date, interval)`:
  - Поддерживает `stock`, `futures`, `index`.
  - Обрабатывает пагинацию (по 100 свечей за раз).
  - Преобразует ответ API в DataFrame с колонками: `secid, ts, open, high, low, close, volume, oi`.
- Метод `load_asset(secid, asset_type, from_date, till_date, interval)`:
  - Вызывает `fetch_candles` и сохраняет результат в `raw_candles` через `database.py`.
  - Обновляет мета-информацию.

### 3. `indicators.py` – расчёт индикаторов
Класс `IndicatorCalculator`:
- Принимает DataFrame с колонками `open, high, low, close, volume`.
- Методы:
  - `ema(period)` – экспоненциальная скользящая средняя.
  - `rsi(period=14)` – относительная сила.
  - `macd(fast=12, slow=26, signal=9)` – MACD с гистограммой.
  - `obv()` – On-Balance Volume.
  - `bollinger_bands(period=20, std=2)` – полосы Боллинджера.
  - `atr(period=14)` – средний истинный диапазон.
  - `adx(period=14)` – индекс направления тренда.
- Метод `compute_all()` – добавляет все индикаторы в DataFrame и возвращает его.

### 4. `divergence.py` – детектор дивергенций
Класс `DivergenceDetector`:
- Находит локальные максимумы/минимумы цены и индикатора (RSI, MACD, OBV).
- Сравнивает их по времени и значениям.
- Возвращает список дивергенций с типом (бычья/медвежья), индексом свечи и описанием.

### 5. `utils.py` – утилиты
- `ts_to_datetime(ts)` – преобразует Unix timestamp в `YYYY-MM-DD HH:MM:SS`.
- `ts_to_date(ts)` – преобразует в `YYYY-MM-DD`.

### 6. `config.yaml` – управление активами
Пример файла:
```yaml
assets:
  stocks:
    - SBER
    - GAZP
    - ROSN
    - LKOH
    - VTBR
    - YNDX
    - NVTK
    - PLZL

    - MGNT
  futures:
    - SiU6        # фьючерс на доллар-рубль (пока не загружается)
    - GOLD-9.26   # золото (уточнить код)
    - BR-9.26     # нефть Brent
  indices:
    - IMOEX
    - RGBI
```

#### `load_all.py`
Скрипт для загрузки данных по всем активам из `config.yaml`.

```python
import yaml
from src.database import DatabaseManager
from src.moex_loader import MOEXLoader
from datetime import datetime, timedelta

with open('config.yaml', 'r', encoding='utf-8') as f:
    config = yaml.safe_load(f)

db = DatabaseManager('finance.db')
loader = MOEXLoader(db)

today = datetime.now().strftime('%Y-%m-%d')
three_years_ago = (datetime.now() - timedelta(days=3*365)).strftime('%Y-%m-%d')

for asset_type, secids in config['assets'].items():
    for secid in secids:
        print(f"Загружаем {secid} ({asset_type})...")
        loader.load_asset(secid, asset_type, three_years_ago, today, interval=24)
```

#### `src/database.py`
Модуль для работы с SQLite.

**Класс `DatabaseManager`**:
- `__init__(db_path)` – подключается и создаёт таблицы.
- `_init_db()` – создаёт таблицы `raw_candles`, `continuous_ohlc`, `meta`.
- `insert_raw_candles(df)` – вставляет данные из DataFrame в `raw_candles` (с `INSERT OR REPLACE`).
- `insert_continuous_candles(df)` – аналогично для непрерывного ряда.
- `get_last_ts(secid, table='raw_candles')` – возвращает последний timestamp.
- `upsert_meta(secid, last_ts, source, total_rows)` – обновляет мета-информацию.

---

#### `src/moex_loader.py`
Основной загрузчик данных с MOEX ISS.

**Класс `MOEXLoader`**:
- `BASE_URL = "https://iss.moex.com/iss"`
- `__init__(db_manager)` – принимает экземпляр `DatabaseManager`.
- `_build_url(secid, asset_type, from_date, till_date, interval)` – формирует URL для разных типов активов.
- `async _fetch_page(session, url, start, secid)` – загружает одну страницу с пагинацией.
- `async fetch_candles_async(secid, asset_type, from_date, till_date, interval)` – загружает все свечи за период, возвращает DataFrame.
- `fetch_candles(secid, asset_type, from_date, till_date, interval)` – синхронная обёртка.
- `async fetch_futures_list_async(base_secid)` – получает список контрактов (используется для склейки, пока не работает).
- `get_futures_list(base_secid)` – синхронная обёртка.
- `load_asset(secid, asset_type, from_date, till_date, interval)` – загружает актив, сохраняет в БД и обновляет мета-информацию. Для фьючерсов пока не реализована склейка.

**Важные моменты**: метод `fetch_candles_async` содержит диагностику и универсальное преобразование времени для устранения проблемы с датами 1970 года.

---

#### `src/indicators.py`
Модуль расчёта технических индикаторов.

**Класс `IndicatorCalculator`**:
- `__init__(df)` – принимает DataFrame с `open, high, low, close, volume`.
- `ema(period, column='close')` – экспоненциальная скользящая средняя.
- `rsi(period=14, column='close')` – RSI.
- `macd(fast=12, slow=26, signal=9, column='close')` – возвращает DataFrame с `macd_line, signal_line, histogram`.
- `obv(column='close', volume_col='volume')` – On-Balance Volume.
- `bollinger_bands(period=20, std=2, column='close')` – возвращает `bb_middle, bb_upper, bb_lower, bb_width, bb_position`.
- `atr(period=14)` – Average True Range.
- `adx(period=14)` – Average Directional Index (упрощённая версия).
- `compute_all()` – применяет все методы и возвращает DataFrame с добавленными колонками.

---

#### `src/divergence.py`
Детектор дивергенций.

**Класс `DivergenceDetector`**:
- `__init__(df, window=5, min_distance=3)` – принимает DataFrame с индикаторами.
- `_find_peaks(series)` – находит локальные максимумы и минимумы.
- `detect_divergences(price_col='close', indicator_col='rsi_14', lookback=50)` – ищет дивергенции на заданном индикаторе.
- `scan_all_indicators(lookback=50)` – сканирует по всем доступным индикаторам (`rsi_14`, `macd_line`, `obv`) и возвращает словарь.

**Логика**:
- Находит экстремумы цены и индикатора.
- Сравнивает их по типу (max/max, min/min).
- Если цена обновила экстремум, а индикатор – нет, фиксирует дивергенцию.
